8 Deployment Procedure

All code changes are deployed from the Git repository. Run these commands after every update:

# 1. SSH into server
ssh root@<server-ip>

# 2. Pull latest code
cd /var/www/mjnhealthcare && git pull origin main

# 3. Build and restart affected app(s)
cd apps/api    && pnpm build && pm2 restart mjn-api      # Backend API
cd apps/web    && pnpm build && pm2 restart mjn-web      # Public site
cd apps/portal && pnpm build && pm2 restart mjn-portal   # Client portal
cd apps/admin  && pnpm build && pm2 restart mjn-admin    # Admin console

# 4. Verify all processes are online
pm2 status
If database schema changes were included, run migrations before restarting the API:

cd /var/www/mjnhealthcare/packages/database
export DATABASE_URL="<value from .env>"
npx prisma migrate deploy

1 Scope of Delivered Work

The Developer has designed, developed, and delivered the following digital platform on behalf of the Client:

1.1 Public Marketing Website (mjnhealthcare.com)

  • Full multi-page marketing site — home, services, academy, success stories, blog, contact, get-started, and all destination pages (UAE, UK, US, Ireland, Canada, Australia)
  • SEO optimization: sitemap.xml, structured data, Open Graph meta, robots.txt
  • Bilingual-ready architecture (English / French routing)
  • Mobile-responsive design with scroll-driven carousels and accordion footer
  • WhatsApp chat widget and AI-powered public support bot
  • Lead capture and free consultation booking flow
  • Per-story detail pages for success stories (/success-stories/[slug])

1.2 Client / Candidate Portal (portal.mjnhealthcare.com)

  • Secure authenticated candidate dashboard with KPI cards and activity feed
  • Case management and pipeline tracking with milestone view
  • Document vault — upload, verification status, expiry alerts
  • Payment history and receipt management
  • Multi-step checkout with category grouping, installment support, and Tranzak payment redirect
  • Academy — courses, question banks, study plans, AI study assistant (Claude)
  • Consultation booking with Daily.co video room provisioning
  • Engagement letter signing integration via Dropbox Sign
  • Phone OTP authentication (Africa's Talking)

1.3 Partner Portal (partner.mjnhealthcare.com)

  • Authenticated partner / employer access
  • Opportunity management and candidate pipeline visibility

1.4 Admin Console (admin.mjnhealthcare.com)

  • Staff authentication with role-based access control
  • Caseload management, compliance queue, document verification workflow
  • AI drafts review and approval queue
  • Financial reporting, lead management
  • Course and content management, consultant and payout management

1.5 Backend API (api.mjnhealthcare.com)

  • NestJS modular API with 17 modules: Auth, Person, Engagement, Licensing, Staffing, Academy, StudentSupport, Catalog, Order, Payment, Document, Booking, Partner, Notification, Compliance, AI, Consultation
  • Event-driven notifications via email (Brevo), SMS and WhatsApp (Africa's Talking / Twilio)
  • PDF receipt generation with company logo
  • Installment tracking and dunning automation (day 7 → 14 → 21 hold)
  • Document expiry scanning — daily cron, alerts at 30 / 14 / 3 days
  • Dropbox Sign webhook integration for engagement letter completion
  • Tranzak payment processing and HMAC webhook verification
  • Full Prisma schema across all entities with migration history

1.6 Infrastructure & Deployment

  • Hostinger KVM2 VPS provisioned and configured
  • Caddy reverse proxy with automatic SSL (Let's Encrypt)
  • PM2 process management with startup persistence
  • IPv4 and IPv6 dual-stack DNS configuration (Namecheap)
  • Git-based deployment workflow (GitHub: btembong/mjnhealthcare)
